## 🚀 Portfolio Projects

### [Cypress Portfolio](https://github.com/valentinomilanov/cypress-portfolio)
A full-stack QA automation portfolio built with Cypress covering UI, API, and Accessibility testing against a real e-commerce application.
- Page Object Model architecture
- Custom JSONL structured logger
- Three GitHub Actions CI/CD pipelines (smoke, sequential, parallel)
- Docker-based test environment
- Qase test management integration

### [cypress-jsonl-logger](https://github.com/valentinomilanov/cypress-jsonl-logger)
An open-source Cypress plugin that generates structured JSONL logs for test steps, verifications, info messages, and accessibility violations.
- ESM compatible
- Browser/Node runtime separation
- Custom commands: `logStep`, `logVerification`, `logInfo`, `logClickButton`, `logEnterValueToField`, `logViolation`
